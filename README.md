# Mnyovu's Sneaker Wash & Shoe Care — Website

This is a mobile-first static website built from the supplied Mnyovu's price list and before/after photos.

## Files
- `index.html` — the website structure and wording
- `style.css` — design/responsive layout
- `script.js` — WhatsApp booking number + mobile menu
- `assets/` — supplied images

## IMPORTANT: before going live
1. Open `script.js`.
2. Find `WHATSAPP_NUMBER`.
3. Replace `2779XXXXXXX` with Mnyovu's real WhatsApp number in international format, without `+`, spaces or brackets.
4. Test the WhatsApp button on a phone.
5. Confirm the address, Instagram handle and prices with Mnyovu.
6. Do not publish a private phone number until Mnyovu has approved it.

## Managing it from a phone
Recommended workflow:
- Keep the project in a GitHub repository.
- Connect the repository to Netlify.
- Edit `index.html`, `style.css` or `script.js` using GitHub's web editor when needed.
- Netlify can automatically deploy changes pushed to the connected Git repository.
- Keep the original project ZIP as a backup.

## What you should update regularly
- Prices and services
- WhatsApp number
- New before/after photos
- Instagram link
- Business hours
- Holiday/temporary closure notices
- Any new delivery/drop-off/pick-up rules

## What the current site does NOT have
- Online payment
- Customer accounts
- A database
- Automated booking calendar
- Admin dashboard
- Automatic order tracking

Those can be added later if the business grows.

## Business-management recommendation
For a small sneaker-wash business, start simple:
1. Website → brings customers in.
2. WhatsApp → handles enquiries/bookings.
3. A simple spreadsheet → tracks customer, shoes, service, price, date, status and payment.
4. Instagram → shows before/after proof.
5. Later, add a booking system or custom dashboard only when the volume justifies it.
